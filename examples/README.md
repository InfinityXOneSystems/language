# Language Examples

This directory contains example programs demonstrating various features of the Language programming language.

## Basic Examples

### hello_world.lang
The classic "Hello, World!" program - a simple introduction.

### variables.lang
Demonstrates variable declaration, basic operations, and data types:
- Variable declarations with `let` and `const`
- Arithmetic operations
- String concatenation
- Boolean operations

### control_flow.lang
Shows control flow structures:
- `if-else` statements
- `if-elif-else` chains
- `while` loops
- `for` loops with ranges
- `for` loops with arrays

## Intermediate Examples

### functions.lang
Explores function definition and usage:
- Simple functions
- Functions with multiple parameters
- Recursive functions
- Higher-order functions
- Arrow functions

### arrays.lang
Demonstrates array operations:
- Creating and accessing arrays
- Array methods (push, pop, map, filter, reduce)
- Nested arrays
- Functional programming with arrays

### objects.lang
Shows object-oriented features:
- Object literals
- Methods in objects
- The `this` keyword
- Nested objects

## Advanced Examples

### classes.lang
Demonstrates class-based programming:
- Class definition
- Constructors
- Methods
- Inheritance with `extends`
- Class hierarchies

## Running Examples

To run an example (once the interpreter is implemented):

```bash
language examples/hello_world.lang
```

## Learning Path

We recommend going through the examples in this order:

1. `hello_world.lang` - Get started
2. `variables.lang` - Learn about data types
3. `control_flow.lang` - Understand program flow
4. `functions.lang` - Master functions
5. `arrays.lang` - Work with collections
6. `objects.lang` - Understand objects
7. `classes.lang` - Learn OOP concepts
